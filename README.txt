REBUILD WORKOUT TRACKER — VERSION 2.0.0

WHAT CHANGED
- Orange mobile-first redesign
- Today dashboard and weekly progress
- Faster one-exercise-at-a-time workout entry
- Automatic saving
- Copy last workout, repeat previous set, and Match Left to Right buttons
- Separate knee and hip pain tracking
- Next-day lower-body pain check-in
- Weight graph, workout history, consistency, and pain trend
- Dark/light/phone theme setting
- More reliable app updates

IMPORTANT: EXISTING DATA
The storage key is intentionally unchanged. Replacing the old files at the same GitHub Pages URL should preserve data already stored on your phone. Export a backup before updating anyway.

UPDATE YOUR GITHUB PAGES APP
1. In the app, open More and tap Export full backup.
2. In the GitHub repository, replace index.html, manifest.webmanifest, sw.js, icon-192.png, and icon-512.png with these files.
3. Commit the changes to main.
4. Wait for GitHub Pages deployment to finish.
5. Open the app, go to More, and tap Check for app update. Then fully close and reopen it.

DATA PRIVACY
Workout data remains in the browser on your phone. It is not committed to GitHub.
